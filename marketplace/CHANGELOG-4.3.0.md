## 4.3.0 · 素笺

### 新增：应用内检查与一键更新

以后的新版本不必再去模块市场找。「素笺」打开时和每天一次查看 LSPosed 模块仓库里的最新正式版，有新版本就在设置页顶部放一张卡片：版本号、这一版改了什么、大小和发布日期，「更新内容」里是完整的更新说明。

- **一键更新**：点「立即更新」，下载、校验、安装一路走完，进度就在卡片里。下载先走模块仓库自己的镜像，不通再走 GitHub；仓库页暂时连不上时，改从 GitHub 读同一份发布。
- **只装真的素笺**：装之前核对包名、版本号和签名，与当前安装的不一致就不装，并说明原因。草稿和预发布版本不会推送。
- **只需允许一次**：第一次更新需要在系统设置里允许「素笺」安装应用；允许后回到设置页，会自动接着装。在本机（ColorOS 17）上，系统随后直接完成安装，不再弹确认框。
- **不打扰**：后台发现新版本只通知一次，在设置页里已经看到的版本不再通知；更新完成后提醒重新启动笔记和便签。设置页底部可以关掉自动检查，关掉后点版本那一行仍能手动检查。
- 中途可以取消；下载过的安装包会留到装上为止，取消系统确认后再点更新不必重新下载。

素笺联网只为检查和下载更新，不上传任何内容。为此新增网络、安装应用、通知和开机后保留每日检查这几项权限。

### 升级后

这一版本身仍需从模块市场安装；从 4.3.0 往后的版本，在「素笺」里就能直接更新。装好后重新启动笔记和便签，让新版本接管分享。

验证：本机 ColorOS 17.0 / Android 17 / LSPosed 2.2.1。用换了包名的副本对着本地模拟的模块仓库走完整条路径：发现新版本（跳过预发布）、读更新说明、仓库下载地址 404 时改走 GitHub、首次申请安装权限后自动续装、静默安装成功、「已更新」提示由系统重新打开的设置页接手、仓库页返回 403 时改读 GitHub、签名不同的安装包被拒并删除、下载中途取消。设计测试新增发布解析、Markdown 说明转换与更新卡片四种状态（含深色、2 倍字号）的检查，全部通过。

限制：需要用户确认安装的系统上，会弹出系统自己的安装确认框；本机不弹，这条分支只按 Android 标准流程实现，未实机走过。

包名与签名不变，可覆盖升级。
