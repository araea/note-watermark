## 4.1.0 · 素笺

### 修复：素笺没在运行时，水印设置不生效

ColorOS 的启动管理会阻止便签唤起素笺（日志：`OplusAppStartupManager: prevent start com.jy.notewatermark … by contentprovider com.coloros.note`）。以前便签在分享时要向素笺读取设置，素笺进程不在就读不到，只能退回「留白」。选了「不显示」或「自定义」的，往往实际拿到的是留白。

现在由素笺把设置交给便签：每次打开素笺、每次改动设置，都会随状态查询一起送进便签进程，由便签自己保存。分享时先读这份副本，不再依赖素笺是否在运行。只接受素笺本身发来的设置。

**升级后请打开一次素笺**，让设置同步到便签。

### 改进：导出的 HTML 能显示图片

便签正文用附件 ID 引用图片，导出的网页因此打不开图。现在图片会指向同一目录下 `_附件/` 里的对应文件，用浏览器打开即可看到。

验证：本机 ColorOS 16 / 便签 16.7.2。便签冷启动后钩子报告 4.1.0；素笺进程不在、便签也被强行停止时，素笺仍能唤起便签完成同步；便签侧保存的设置与素笺一致；实际导出 16 条便签成功。设计测试全部通过，并新增图片链接改写的检查。手机处于锁屏，本次没有实际走一遍分享页。
